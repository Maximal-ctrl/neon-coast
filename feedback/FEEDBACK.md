# Feedback & Verbesserungsvorschläge

Hier landen die Vorschläge aus dem Spiel (Titelbild → „Feedback & Ideen“), sobald der Cloud-Speicher
eingerichtet ist (docs/ACCOUNTS.md). Abholen mit `node tools/feedback.mjs`, nach dem Umsetzen
`node tools/feedback.mjs --clear`. Vorschläge, die über GitHub gesendet wurden, stehen als Issues mit dem
Label `feedback` im Repository.

_Noch keine Einträge._
